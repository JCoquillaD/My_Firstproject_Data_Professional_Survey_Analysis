# Coffee Operations Analysis Report (Maven Coffee Challenge)

### Project Overview
This project is an operational analysis of a coffee shop chain, focusing on sales performance, transaction trends, and product-level insights. The goal was to transform raw transaction data into an interactive dashboard that helps identify peak hours, top-selling products, and revenue growth opportunities.

### Project Objectives
* **Sales Trend Analysis:** Monitoring daily and monthly revenue patterns to identify peak business periods.
* **Product Performance:** Evaluating which coffee categories and specific products drive the most volume and profit.
* **Operational Efficiency:** Analyzing transaction counts and average order values (AOV) to optimize staffing and inventory.

### Technical Workflow & Skills Applied
* **Advanced Data Cleaning:** Used Power Query to handle date/time formats and categorize products for better granularity.
* **DAX Implementation:** Created measures for Total Revenue, Transaction Counts, and Month-over-Month (MoM) growth.
* **Data Modeling:** Established relationships between sales tables and product/store dimensions for a seamless filter experience.
* **Professional UI/UX:** Applied custom backgrounds and intuitive navigation (Slicers/Tooltips) for a corporate-ready look.

### Tools & Technologies
* **Power BI Desktop:** Core platform for ETL and Visualization.
* **DAX (Data Analysis Expressions):** For dynamic business calculations.
* **Power Query:** For robust data transformation.

### 📝 Personal Note on This Project
> "Compared to my foundational projects, this report demonstrates my progress in handling more complex datasets and implementing advanced DAX functions. It reflects my growing ability to provide actionable business insights through cleaner layouts and more sophisticated data modeling."

### Key Insights
* **Peak Periods:** Identified specific hours with the highest transaction volume for better staff scheduling.
* **Revenue Drivers:** Determined which products contribute most to the bottom line versus those that just have high volume.
