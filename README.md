# Data Professional Survey Analysis (Foundational Project)

### Project Overview
This project serves as my foundational entry into Data Analytics using Power BI. It analyzes survey data from 630 respondents in the data industry. This project involved end-to-end processing—from raw survey data cleaning to strategic dashboard design.

### Source & Mentorship
* **Learning Source:** Guided by **Alex The Analyst**. 
*   https://www.youtube.com/@AlexTheAnalyst
* **Key Lessons:** Through this project, I learned the core responsibilities of a Data Analyst: how to choose the right visuals, how to structure a report for stakeholders, and the best practices in data storytelling.

### Project Objectives & Technical Workflow
* **Data Cleaning & Transformation (Power Query):** * Standardized data types and used "Replace Values" to handle inconsistent survey responses.
    * Computed the **Average Salary** for Data Analysts and other roles to provide meaningful benchmarks.
* **Strategic Visualization & Design:** * Studied dashboard essentials to determine which metrics provide the most value versus unnecessary clutter.
    * Applied professional design principles to ensure the report is intuitive and functional.
